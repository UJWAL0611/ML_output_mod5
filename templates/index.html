How it works

01
🌐

Scrape

Static HTML scraping first; if reviews load via JavaScript, Playwright headless Chromium renders the page and extracts them.

02
🧹

Preprocess

HTML stripping, lowercasing, stopword removal, and WordNet lemmatization clean the raw text.

03
📐

Vectorise

TF-IDF with bigrams converts the cleaned text into a 50,000-feature sparse matrix.

04
🧠

Classify

A Logistic Regression model trained on labelled reviews predicts Fake or Genuine with a probability score.

05
🔍

Heuristic Check

Linguistic and structural rules scan for excessive caps, superlatives, template phrases, and repetition patterns.

06
✨

AI Cross-Check

Gemini 2.0 Flash semantically evaluates each review for authenticity and provides a confidence score + short reason.
